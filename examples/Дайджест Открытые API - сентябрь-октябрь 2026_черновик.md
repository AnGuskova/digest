**Ассоциация ФинТех** · Центр компетенций по Открытым API · Данные на 04.11.2026

## Ключевые итоги

- **Экспертный совет АФТ согласовал 4 стандарта Открытых API.** 21.10.2026 пакет новых версий стандартов[^1], включая спецификации по счетам и согласиям физлиц, одобрен для направления в Банк России на утверждение и публикацию. Сроки перехода не согласованы - их рассмотрят 12.11.2026.
- **Согласия физлиц на Госуслугах (Платформа коммерческих согласий, ПКС).** 26.10.2026 АФТ представила проект правил: Госуслуги только информируют клиента о событиях с его согласием и не призывают его отзывать. Позиции банков - до 25.11.2026, затем проект направят в Банк России и Минцифры.
- **Оператор среды: единое соглашение для всех участников.** 30.09.2026 АФТ представила концепцию Соглашения с Оператором взамен отдельных соглашений по каждой интеграции. Отзывы участников обсудят на следующем заседании РГ.

## Основные направления

### 1. Оператор среды Открытых API

- В песочнице АФТ развернуты ключевые компоненты прототипа Оператора.
- Согласованы ролевые правила участников: перед тем как делиться данными, банк автоматически проверит, есть ли у запрашивающего нужная роль.
- АФТ подготовила проект регламента подключения к Оператору - на рассмотрении у участников.

Участники: Банк «Пример», Банк «Образец», Банк «Модель», Банк «Вектор»

### 2. Согласия физлиц на Госуслугах (ПКС)

- Все сценарии пилота (выдача и отзыв согласия) прошли Банк «Пример» и Банк «Модель».
- Уведомления Госуслуг о согласиях предлагается сделать только информационными: основным каналом общения с клиентом остается банк.
- АФТ предложила метрики SLA для ПКС: доступность, время ответа, устранение сбоев.

Участники: Минцифры России, Банк «Пример», Банк «Образец», Банк «Модель»

### 3. Безопасность обмена данными

- Новую версию стандарта «Профили API» согласовали ДИБ Банка России, Банк «Пример», Банк «Образец» и Банк «Вектор»; далее - согласование Экспертным советом АФТ.
- Запросам на доступ к данным клиента присвоят уникальный номер - при сбое банки быстро найдут запрос в своих системах.

Участники: ДИБ Банка России, Банк «Пример», Банк «Образец», Банк «Вектор»

### 4. Мультибанкинг для физлиц

- Экспертный совет согласовал новые версии стандартов по счетам и согласиям физлиц: в них добавлены вклады и накопительные счета.
- Переход на них с 01.12.2026 не согласован: Банк «Образец» не готов. 12.11.2026 Экспертный совет рассмотрит новый срок перехода.
- Число банков, которые уже пилотируют новые версии: В предоставленных данных информации нет.

Участники: Банк «Пример», Банк «Образец», Банк «Модель», Банк «Опора»

### 5. Подтверждение дохода через Открытые API

- В экспериментальном правовом режиме (ЭПР) банки с согласия заемщика проверят получение данных о его доходе по Открытым API для расчета показателя долговой нагрузки (ПДН).
- Разработан проект Требований к данным: он определяет, что считать доходом в рамках ЭПР.
- Проект Программы ЭПР на согласовании в ДФТ Банка России.

Участники: ДФТ Банка России, Банк «Пример», Банк «Модель», Банк «Опора»

### 6. Мультибанкинг для бизнеса

- Банк «Пример» и Банк «Вектор» согласовали правила передачи информации о блокировке счета - основу для работы с заблокированными счетами в согласии.
- Налоговые реквизиты в выписках обновлены в соответствии с требованиями Банка России и Минфина; изменения на согласовании у банков.

Участники: Банк «Пример», Банк «Образец», Банк «Вектор»

### 7. Платежи бизнеса

- Спецификация переводов юрлиц по длительным поручениям на финальном согласовании.
- АФТ разработан сценарий подписания платежа, подходящий для обоих типов подписи - УКЭП и УНЭП.

Участники: Минцифры России, ДНПС Банка России, Банк «Пример», Банк «Образец»

### 8. Медстрахование (ДМС)

- Цель пилота - автоматизировать обмен данными по ДМС между страховыми и клиниками: прикрепление застрахованного сокращается с нескольких дней до минут.
- 07.10.2026 страховая компания «Щит» и клиника «Здоровье» выполнили первый успешный запрос.

Участники: страховая компания «Щит», страховая компания «Гарант», клиника «Здоровье»

[^1]: Общие положения 2.1.0, Правила взаимодействия 3.0.0, 2 спецификации по счетам и согласиям ФЛ.
