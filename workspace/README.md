# Рабочая папка

- `istochniki.md`: перечень подключённых источников по образцу `nastroyki/istochniki.md`.
- `kontakty.md`: контакты для второй страницы по образцу `nastroyki/kontakty.md`.
- `inputs/`: материалы за период (протоколы, решения, расшифровки, дорожная карта); выгрузка из облака по папкам `inputs/<код источника>/`.
- `outputs/`: готовые дайджесты.

Содержимое папки в git не попадает. Здесь хранится только этот файл.
