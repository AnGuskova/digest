# Рабочая папка

- `inputs/`: материалы за период (протоколы, статусы, решения, расшифровки) и прошлый выпуск.
- `outputs/`: черновики и итоговые файлы дайджеста.
- `kontakty.md`: заполненная таблица «Как подключиться» (образец `nastroyki/kontakty.md`).
- `rabochie-gruppy.md`: при необходимости заполненная копия `nastroyki/rabochie-gruppy.md` с участниками и ID папок.

Содержимое папки в git не попадает. Здесь хранится только этот файл.
