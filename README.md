# Дайджест ЦК по Открытым API

ИИ-агент, который готовит дайджест Центра компетенций по Открытым API Ассоциации ФинТех за квартал, полугодие или год. Дайджест занимает одну страницу: ключевые результаты, события и достижения АФТ и участников по инициативам дорожной карты и рабочим группам, без технических подробностей. Каждая строка дайджеста прослежена до источника в служебной части.

Агент не привязан к конкретному ИИ. Правила лежат в текстовых файлах и работают с Claude, ChatGPT, DeepSeek, GigaChat, YandexGPT, локальными моделями и агентными инструментами.

## Быстрый старт

1. Заполните `nastroyki/rabochie-gruppy.md` (рабочие группы), `workspace/istochniki.md` по образцу `nastroyki/istochniki.md` (облачные папки и сервисы встреч) и `nastroyki/dorozhnaya-karta.md` (инициативы из утверждённой дорожной карты).
2. Выберите способ подключения ИИ: `docs/nastroyka-ii.md`.
3. Дайте запрос из `prompts/zapros.md` и приложите материалы за период.
4. Проверьте черновик: `python3 scripts/proverka.py workspace/outputs/<файл>_черновик.md`.
5. Соберите итоговый файл по шаблону: `python3 scripts/sborka.py workspace/outputs/<файл>_черновик.md`. Нужна библиотека `python-pptx` (`pip install python-pptx`).

На выходе два файла:

- **черновик** `ГГГГ-ММ-ДД_дайджест_<период>_черновик.md`: текст дайджеста и служебная часть с метками [ФАКТ], [ПРЕДЛОЖЕНИЕ], [ПРЕДПОЛОЖЕНИЕ], ссылками на источники и трассировкой. Его проверяете вы;
- **итоговый файл** `ГГГГ-ММ-ДД_дайджест_<период>.pptx`: оформлен по шаблону АФТ (`templates/daydzhest.pptx`), без меток и служебной части. Его получает адресат. PDF при необходимости сохраняется из PowerPoint.

Правки вносятся в черновик, после чего итоговый файл собирается заново.

Образец на вымышленных данных: `examples/` (черновик, итоговый файл, контакты).

## Структура

```
AGENTS.md                      правила и порядок работы агента (главный файл)
CLAUDE.md                      ссылка на AGENTS.md для Claude Code
prompts/system-prompt.md       короткие инструкции для чат-интерфейсов
prompts/zapros.md              запрос на подготовку дайджеста
templates/daydzhest.md         шаблон черновика (текст, метки, трассировка)
templates/daydzhest.pptx       шаблон итогового файла АФТ
nastroyki/                     рабочие группы, образец перечня источников, дорожная карта, контакты
scripts/proverka.py            проверка структуры, объёма, трассировки, меток
scripts/sborka.py              сборка итогового файла .pptx из черновика
scripts/zapusk.py              запуск через API в формате OpenAI
docs/nastroyka-ii.md           подключение к разным ИИ
examples/                      пример на вымышленных данных
workspace/                     рабочие материалы и результаты, в git не попадают
```

## Правила работы с данными

- Рабочие материалы и готовые дайджесты лежат в `workspace/` и в git не попадают (`.gitignore` и проверка `.githooks/pre-commit`).
- Включить проверку перед коммитом: `git config core.hooksPath .githooks`.
- Ключи API хранятся в `.env`, он тоже не попадает в git.
- Подключённые источники агент только читает.

## Как заполнить настройки и подключить ИИ, которым вы пользуетесь

1. Заполните `nastroyki/dorozhnaya-karta.md`: Откройте файл, нажмите значок карандаша справа вверху и перенесите инициативы из утверждённой дорожной карты дословно. Затем нажмите «Commit changes».
2. Проверьте `nastroyki/rabochie-gruppy.md`: совпадают ли с текущими состав и названия РГ.
   Облачные папки и сервисы встреч перечислите в `workspace/istochniki.md` по образцу `nastroyki/istochniki.md`: так ID папок и ссылки не попадут в публичный репозиторий. Как подключить облако к ИИ: `docs/nastroyka-ii.md`, раздел «Облачные источники».
   Контакты координаторов для второй страницы заполните в `workspace/kontakty.md` по образцу `nastroyki/kontakty.md`: так ФИО и почта не попадут в git.
3. Выберите ИИ и настройте его по `docs/nastroyka-ii.md`. Для чата с проектами (Claude, ChatGPT) это 3 действия:
   создать проект «Дайджест ЦК ОПИ»
   вставить в инструкции проекта текст `prompts/system-prompt.md`
   загрузить в файлы проекта `AGENTS.md`, `templates/daydzhest.md`, `templates/daydzhest.pptx`, `scripts/sborka.py` и файлы из `nastroyki/`
Сделайте пробный дайджест. Например, за III квартал 2026 года: запрос возьмите из `prompts/zapros.md` и приложите протоколы за этот период.

## Как дополнять

- Правила меняются в `AGENTS.md`. Если правило касается чат-интерфейсов, поправьте и `prompts/system-prompt.md`.
- После изменения шаблона или проверки запустите `python3 scripts/proverka.py examples`: пример должен проходить без ошибок.
- После изменения `templates/daydzhest.pptx` или `scripts/sborka.py` пересоберите пример и откройте его: `python3 scripts/sborka.py examples/2026-10-05_дайджест_3кв-2026_черновик.md --kontakty examples/kontakty-primer.md`.
- В шаблоне PPTX скрипт ищет фигуры по именам (`summary-title-1`, `wg-card-1`, `contacts-table` и др.) и слово «ПЕРИОД». Меняйте цвета и шрифты свободно, а имена фигур сохраняйте.
