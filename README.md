# Дайджест ЦК по Открытым API

ИИ-агент, который готовит дайджест «Открытые API» Центра компетенций по Открытым API Ассоциации ФинТех. Дайджест занимает 2 страницы A4 и показывает результаты всех активных рабочих групп за период, по умолчанию за два месяца («сентябрь - октябрь 2026»). Его читают бизнес-аналитики, владельцы продукта и топ-менеджеры, которые не ходят на рабочие группы. Каждая строка дайджеста прослежена до источника в служебной части черновика.

Агент не привязан к конкретному ИИ. Правила лежат в текстовых файлах и работают с Claude, ChatGPT, DeepSeek, GigaChat, YandexGPT, локальными моделями и агентными инструментами.

## Как устроен выпуск

| Страница | Блоки                                                                                   |
| -------- | --------------------------------------------------------------------------------------- |
| 1        | «Ключевые итоги» (2-3), карточки направлений 1-4, сноска                                 |
| 2        | карточки направлений 5-8, «Полезная информация», «Как подключиться»                     |

8 карточек — постоянные направления по рабочим группам (`nastroyki/rabochie-gruppy.md`): номер, значок, короткое название, 1-3 пункта, строка «Участники». Работа в процессе входит со статусом («на согласовании», «подготовлен проект»), действия регулятора сверяются с его сайтом, пункты прошлого выпуска без нового продвижения не повторяются. Подробно: `AGENTS.md`.

## Быстрый старт

1. Проверьте `nastroyki/rabochie-gruppy.md` (активные РГ и номера карточек) и `nastroyki/spravochnik-terminov.md` (как пишутся термины и организации).
2. Заполните локальные копии, которые не попадают в git: `workspace/kontakty.md` по образцу `nastroyki/kontakty.md` и, если нужно, `workspace/rabochie-gruppy.md` с участниками и ID папок.
3. Выберите способ подключения ИИ: `docs/nastroyka-ii.md`.
4. Дайте запрос из `prompts/zapros.md`, приложите материалы за период и прошлый выпуск.
5. Проверьте черновик: `python3 scripts/proverka.py "workspace/outputs/Дайджест Открытые API - сентябрь-октябрь 2026_черновик.md"`.
6. Соберите итоговый файл: `python3 scripts/sborka.py "workspace/outputs/Дайджест Открытые API - сентябрь-октябрь 2026_черновик.md"`. Нужна библиотека `python-pptx` (`pip install python-pptx`).

На выходе два файла:

- **черновик** `Дайджест Открытые API - <период>_черновик.md`: текст дайджеста и служебная часть с метками [ФАКТ], [ПРЕДЛОЖЕНИЕ], [ПРЕДПОЛОЖЕНИЕ], статусами, ссылками на источники, сравнением с прошлым выпуском и 9 проверками «Понятно менеджеру». Его проверяете вы;
- **итоговый файл** `Дайджест Открытые API - <период>.pptx`: оформлен по шаблону АФТ (`templates/daydzhest.pptx`), без меток и служебной части. Его получает адресат. PDF при необходимости сохраняется из PowerPoint.

Правки вносятся в черновик, после чего итоговый файл собирается заново. Правки комментариями в PPTX: `python3 scripts/kommentarii.py <файл>.pptx`.

Образец на вымышленных данных: `examples/` (черновик, итоговый файл, контакты).

## Правила работы с данными

- Репозиторий публичный. Рабочие материалы, готовые дайджесты, контакты и ID папок лежат в `workspace/` и в git не попадают (`.gitignore` и проверка `.githooks/pre-commit`).
- Включить проверку перед коммитом: `git config core.hooksPath .githooks`. Она останавливает коммит, если в нём файлы из `workspace/`, `.env`, настоящие адреса почты или PPTX с авторами и комментариями.
- Ключи API хранятся в `.env` (образец `.env.example`), он тоже не попадает в git.
- Подключённые источники агент только читает.

## Как подключить ИИ, которым вы пользуетесь

Для чата с проектами (Claude, ChatGPT) это 3 действия:

1. создать проект «Дайджест ЦК ОПИ»;
2. вставить в инструкции проекта текст `prompts/system-prompt.md`;
3. загрузить в файлы проекта `AGENTS.md`, `templates/daydzhest.md`, `templates/daydzhest.pptx`, `scripts/sborka.py`, `scripts/proverka.py`, файлы из `nastroyki/` и заполненные копии из `workspace/`.

Остальные способы: `docs/nastroyka-ii.md`.

## Как дополнять

- Правила меняются в `AGENTS.md`. Если правило касается чат-интерфейсов, поправьте и `prompts/system-prompt.md`.
- Новые термины и организации добавляются в `nastroyki/spravochnik-terminov.md`: `proverka.py` начнёт предупреждать о вариантах из колонки «Не пишем».
- После изменения шаблона или проверки запустите `python3 scripts/proverka.py examples`: пример должен проходить без ошибок.
- После изменения `templates/daydzhest.pptx` или `scripts/sborka.py` пересоберите пример и откройте его: `python3 scripts/sborka.py "examples/Дайджест Открытые API - сентябрь-октябрь 2026_черновик.md" --kontakty examples/kontakty-primer.md`.
- В шаблоне PPTX скрипт ищет фигуры по именам: `summary-title-1…3`, `summary-text-1…3`, `summary-icon-1…3`, `summary-footnote-1`, `wg-card/badge/icon/title/text/members-1…8`, `info-*`, `resource-*`, `contacts-table`, и слово «ПЕРИОД». Цвета, шрифты и значки меняйте свободно, имена фигур сохраняйте.
