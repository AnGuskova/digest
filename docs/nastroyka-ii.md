# Как подключить агента к разным ИИ

Правила агента лежат в обычных текстовых файлах и от модели не зависят:

| Файл                            | Зачем                                                           |
| ------------------------------- | --------------------------------------------------------------- |
| `AGENTS.md`                     | Полные правила и порядок работы. Главный файл                   |
| `prompts/system-prompt.md`      | Короткая выжимка правил для поля «инструкции» в чат-интерфейсах |
| `prompts/zapros.md`             | Текст запроса на подготовку дайджеста                           |
| `templates/daydzhest.md`        | Шаблон дайджеста                                                |
| `nastroyki/rabochie-gruppy.md`  | Рабочие группы и папки с материалами                            |
| `nastroyki/dorozhnaya-karta.md` | Инициативы дорожной карты                                       |
| `scripts/proverka.py`           | Формальная проверка готового дайджеста                          |
| `scripts/zapusk.py`             | Запуск через API любой модели с форматом OpenAI                 |

Перед началом заполните `nastroyki/rabochie-gruppy.md` и `nastroyki/dorozhnaya-karta.md`.

## Важно до начала работы

- Внутренние документы АФТ передаются во внешний ИИ только по правилам информационной безопасности вашей организации. Если правила запрещают внешние сервисы, используйте локальную модель (раздел 5).
- Поле инструкций в чат-интерфейсах ограничено по длине. Поэтому в него вставляется короткий `prompts/system-prompt.md`, а полные правила (`AGENTS.md`) загружаются файлом.
- Если ИИ не умеет запускать скрипты, проверьте готовый файл сами: `python3 scripts/proverka.py <файл>`.

## 1. Чат с проектами или собственными ассистентами

Подходит для Claude (Проекты), ChatGPT (Проекты или собственные GPT) и других сервисов, где можно сохранить инструкции и файлы.

1. Создайте проект или ассистента, например «Дайджест ЦК ОПИ».
2. В поле инструкций вставьте текст `prompts/system-prompt.md`.
3. Загрузите в файлы проекта: `AGENTS.md`, `templates/daydzhest.md`, `nastroyki/rabochie-gruppy.md`, `nastroyki/dorozhnaya-karta.md`.
4. Если сервис подключён к Google Drive, разрешите доступ только на чтение к папкам из `nastroyki/rabochie-gruppy.md`. Если не подключён, прикладывайте файлы к запросу.
5. Для каждого дайджеста откройте новый чат в проекте, вставьте запрос из `prompts/zapros.md` и приложите материалы за период.
6. Сохраните ответ в файл `ГГГГ-ММ-ДД_дайджест_<период>.md` и проверьте его скриптом.

## 2. Чат без сохранённых инструкций

Подходит для DeepSeek, GigaChat, YandexGPT и любых других чатов.

1. Откройте новый чат.
2. Приложите файлы: `AGENTS.md`, `templates/daydzhest.md`, `nastroyki/rabochie-gruppy.md`, `nastroyki/dorozhnaya-karta.md` и материалы за период.
3. Первым сообщением вставьте текст `prompts/system-prompt.md`, затем запрос из `prompts/zapros.md`.
4. Если чат не принимает файлы, вставьте их текст в сообщение. Порядок тот же: правила, шаблон, настройки, материалы.
5. Сохраните ответ в файл и проверьте его скриптом.

## 3. Агентные инструменты, которые работают с папкой репозитория

Подходит для Claude Code, Codex CLI и других инструментов, которые читают `AGENTS.md` из корня репозитория.

1. Клонируйте репозиторий и откройте его в инструменте.
2. Инструмент сам прочитает `AGENTS.md`. Claude Code читает `CLAUDE.md`, а он ссылается на `AGENTS.md`.
3. Положите материалы в `workspace/inputs/` или подключите облачные папки только на чтение.
4. Дайте запрос из `prompts/zapros.md`. Инструмент сохранит файл в `workspace/outputs/` и запустит `scripts/proverka.py`.

Если инструмент читает файл с другим именем, создайте его в корне с одной строкой: «Правила агента: AGENTS.md. Прочитай его перед работой».

## 4. Через API: скрипт `scripts/zapusk.py`

Подходит для провайдеров с форматом запросов OpenAI Chat Completions: OpenAI, DeepSeek, Anthropic в режиме совместимости, OpenRouter, YandexGPT, Ollama, LM Studio и другие. Нужен только Python 3.8 или новее, сторонние библиотеки не нужны.

1. Скопируйте `.env.example` в `.env` и заполните адрес API, ключ и имя модели. Адрес и имя модели сверьте с документацией провайдера.
2. Сохраните материалы за период как текст (`.md`, `.txt`) в `workspace/inputs/`.
3. Запустите:

   ```bash
   python3 scripts/zapusk.py --period "III квартал 2026" --data-sreza 05.10.2026 --imya 3кв-2026 workspace/inputs/*.md
   ```

4. Скрипт сохранит дайджест в `workspace/outputs/` и сразу проверит его.

Если провайдер требует другой заголовок авторизации, задайте `AI_AUTH_SCHEME` в `.env`. Если провайдер не поддерживает формат OpenAI, используйте чат (раздел 1 или 2).

## 5. Локальная модель

Документы не покидают компьютер.

1. Установите Ollama или LM Studio и загрузите модель, которая хорошо пишет по-русски и принимает длинный текст.
2. В `.env` укажите `AI_BASE_URL=http://localhost:11434/v1` (Ollama) или адрес LM Studio и имя модели. Ключ не нужен.
3. Запустите `scripts/zapusk.py` как в разделе 4.

Небольшие локальные модели хуже соблюдают правила. Проверяйте результат скриптом и вручную.

## Как сменить ИИ

Правила, шаблон и настройки остаются прежними. Меняется только способ подключения: другой раздел этого файла или другие строки в `.env`.
