# Подключённые источники

Образец перечня мест, где агент ищет материалы за период. Свой перечень пользователь ведёт в `workspace/istochniki.md`: эта папка в git не попадает, поэтому ID папок, ссылки и названия внутренних встреч не окажутся в публичном репозитории. Агент читает `workspace/istochniki.md`, а если его нет, этот файл. Агент перечень не меняет.

Источник подключается одним из трёх способов:

| Способ           | Как работает                                                                                          | Что нужно от пользователя                                              |
| ---------------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Коннектор ИИ     | ИИ сам читает облачную папку или сервис встреч (например, коннектор Google Drive в Claude или ChatGPT) | подключить коннектор с доступом только на чтение к папкам из перечня   |
| Выгрузка         | Пользователь скачивает файлы из облака в `workspace/inputs/<код источника>/`                          | выгрузить папку целиком, сохранив имена файлов и вложенные папки       |
| Вложение к чату  | Файлы прикладываются к запросу                                                                        | приложить все файлы за период и написать, из какой папки они взяты     |

Способ выбирается для каждого источника отдельно. Если коннектора к сервису нет (например, к Яндекс Диску или облаку организации), используется выгрузка.

Строки можно добавлять, удалять и переименовывать. Код источника пишется в ссылках черновика и в имени папки выгрузки.

## Как указать адрес

- Google Drive: ID папки, то есть часть ссылки после `/folders/` без `?usp=...`. Общий диск указывается так же.
- Яндекс Диск, OneDrive, SharePoint, Nextcloud, облако организации: путь к папке от корня диска или ссылка на папку.
- Сервис встреч: название пространства или календаря и признак, по которому агент находит встречи РГ (например, слово «РГ» в названии встречи).
- Выгрузка: путь `workspace/inputs/<код источника>/` и дата выгрузки, например «выгружено 03.10.2026».

## Что проверить при подключении

1. Доступ только на чтение. Если сервис даёт ИИ только полный доступ, лучше выгрузка.
2. Правила информационной безопасности организации разрешают передавать эти документы выбранному ИИ.
3. Доступ открыт ко всем вложенным папкам. Недоступная вложенная папка выглядит как пустая.
4. Расшифровки встреч сохраняются дословно. Сводка ИИ без расшифровки решений не подтверждает (`AGENTS.md`, п. 2.6).
