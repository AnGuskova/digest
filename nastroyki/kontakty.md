# Контакты координаторов АФТ

Таблица для блока «Как подключиться» на второй странице итогового дайджеста (`templates/daydzhest.pptx`). Ведёт пользователь; агент читает и не меняет. Контакты берутся только из этой таблицы, а не из протоколов и переписки.

Репозиторий публичный: не пишите сюда ФИО и почту. Заполненную копию положите в `workspace/kontakty.md`: в git она не попадает, а `scripts/sborka.py` берёт её первой. Пока таблица не заполнена, блок «Как подключиться» в итоговый файл не входит.

В первой колонке через «;» перечисляются рабочие группы координатора, как они должны выглядеть в таблице: например, «Стандарты ЮЛ: выписки, переводы, согласия; Стандарты ФЛ: счета, переводы, согласия». Каждая станет отдельной строкой с маркером.
