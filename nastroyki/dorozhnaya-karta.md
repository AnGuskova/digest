# Дорожная карта АФТ в части Открытых API (необязательно)

Дайджест строится по активным рабочим группам (`nastroyki/rabochie-gruppy.md`), а не по дорожной карте. Эта таблица нужна, только если пользователь хочет сверять вехи: агент тогда проверяет, совпадает ли статус направления с вехой, и пишет связь в «Карту направлений» черновика. Структура дайджеста от неё не меняется.

Пользователь переносит инициативы из утверждённого документа АФТ дословно. Агент читает файл и не меняет. Если таблица пуста, сверка с дорожной картой не проводится; инициативы по памяти не восстанавливаются.
