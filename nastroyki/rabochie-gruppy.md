## Порядок использования

1. Протоколы читаются первыми. Просматриваются все файлы каждой папки, включая вложенные папки, на всех страницах списка. Каждый файл читается целиком; обрезанный текст не считается прочитанным.
2. Файл с одним ID учитывается один раз, даже если он виден из нескольких папок.
3. Материалы встреч вне РГ не являются решениями РГ. Темы из них идут как **[ПРЕДЛОЖЕНИЕ]** или открытый вопрос.
4. Каждая находка относится к РГ по коду из первой таблицы. Если отнести нельзя, код «вне РГ».
5. Если папка недоступна, это пишется в «Открытые вопросы». Пробел по памяти не восполняется.
6. В «Источники» дайджеста указывается число просмотренных файлов по каждой папке и список файлов, которые не удалось прочитать.
