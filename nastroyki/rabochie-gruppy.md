# Рабочие группы и папки источников

Список ведёт пользователь. Агент читает его перед подготовкой дайджеста и не меняет.

Если репозиторий публичный, не пишите сюда ID папок и состав участников, если он не публикуется. Заполненную копию положите в `workspace/rabochie-gruppy.md`: в git она не попадает, и агент читает её первой.

Облачные папки только читаются. ID папки Google Drive: часть ссылки после `/folders/`, без `?usp=...`. Если ИИ не подключён к Google Drive, пользователь прикладывает файлы к запросу или кладёт их в `workspace/inputs/`.

## Порядок использования

1. Протоколы читаются первыми. Просматриваются все файлы каждой папки, включая вложенные папки, на всех страницах списка. Каждый файл читается целиком; обрезанный текст не считается прочитанным.
2. Файл с одним ID учитывается один раз, даже если он виден из нескольких папок.
3. Сводки и презентации проверяются по протоколам, а утверждения о действиях регулятора по его сайту (AGENTS.md, п. 2.5): в них встречаются ошибки.
4. Материалы встреч вне РГ не являются решениями РГ. Темы из них идут со статусом «предложено» или открытым вопросом.
5. Каждая находка относится к карточке по номеру из первой таблицы. Если отнести нельзя, «вне РГ».
6. Если папка недоступна, это пишется в «Открытые вопросы». Пробел по памяти не восполняется.
7. В «Источники» дайджеста указывается число просмотренных файлов по каждой папке и список файлов, которые не удалось прочитать.
